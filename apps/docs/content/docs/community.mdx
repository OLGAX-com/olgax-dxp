## Where to go for what

| I want to... | Go to |
| --- | --- |
| Ask how to do something | [Discord](https://discord.gg/EAXcCXgUz2) |
| Report a bug | [GitHub issues](https://github.com/OLGAX-com/olgax-dxp/issues) |
| Request a feature | [GitHub issues](https://github.com/OLGAX-com/olgax-dxp/issues), or start on Discord |
| Show off a site | [Discord](https://discord.gg/EAXcCXgUz2) |
| Contribute code or docs | [Local development](/docs/contributing/development) |
| Fix a typo on a docs page | Use **Edit on GitHub** at the bottom of the page |

## Asking a good question

A few details get you a fast answer:

- What you ran, and what you expected.
- The exact error text.
- Your Node.js version, your OS and your package manager.
- The `@olgax.com/*` versions from your `package.json`.

## Contribute

Everything helps: a typo fix, a clearer sentence, a new component or a bug report with steps to reproduce it. Start with
[Local development](/docs/contributing/development).
