The default, themeable component library for Olgax DXP. Each component is a plain React component registered with Puck
through [`@olgax.com/sdk`](/docs/reference/sdk), and styled only with `--olgax-*` CSS variables.

```bash
pnpm add @olgax.com/components
```

## Usage

```ts
import { components } from "@olgax.com/components";
import type { Config } from "@puckeditor/core";

export const config: Config = { components };
```

Import the tokens once to get the default theme:

```ts
import "@olgax.com/components/dist/tokens.css";
```

Scaffolded sites already do this. Override any `--olgax-*` property to retheme, or add the optional dark theme:

```ts
import "@olgax.com/components/src/themes/dark.css";
```

See [Theming](/docs/guides/theming).

## Common props

Every component also has:

- **Color overrides**: optional `backgroundColor`, `primaryColor` and `textColor` hex values that affect only that
  instance.
- **Show to**: `everyone`, `new-visitors` or `returning-visitors`.

## RelatedPages

`RelatedPages` needs a resolver from [`@olgax.com/datasource`](/docs/reference/datasource), so it does not register
itself on import. Register it from your app:

```ts
import { registerRelatedPages } from "@olgax.com/components";
import { createCollectionResolverFetch } from "@olgax.com/datasource";

registerRelatedPages(createCollectionResolverFetch("/api/related-pages"));
```

Editors set `collection`, `filterField`, `filterValue` and `limit`. `items` is resolved automatically and read-only.
See [Data sources](/docs/guides/data-sources).
